## 🎯 What This App Does

A frontend prototype that simulates a **controlled access flow** — users must complete QR payment, receive an access code, and verify their email before a protected link is unlocked. Unauthorized users are blocked at every step.

---

## 🔐 Access Flow

```
Step 1 → User scans QR code to simulate payment
Step 2 → User receives a unique access code
Step 3 → User verifies email using verification code
Step 4 → Protected link is unlocked ✅
         Unauthorized users are blocked ❌
```
